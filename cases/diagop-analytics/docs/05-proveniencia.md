# Procedência dos materiais

## Fontes disponíveis

- Enunciado da Prática 12 fornecido pela autora nesta conversa e preservado em docs/00-pratica-12.md. Caso hipotético, sem anúncio real verificado.

- CSV anexado nesta conversa, preservado byte a byte em dados/atendimentos_simulados.csv.
- Pedido de análise, pedidos de revisão e respostas presentes nesta conversa.
- Configuração atual do DiagOp consultada durante a preparação do portfólio.

## Natureza de cada documento

- prompts/01-prompts-utilizados.md: transcrições de mensagens disponíveis, com menção/link do plugin removidos.
- retornos/01-retorno-inicial.md: resumo estruturado, identificado como resumo.
- retornos/02-retorno-revisado.md: transcrição do último retorno de revisão disponível.
- agente/instrucoes.md: conteúdo da configuração consultada, documentado para estudo; não inclui endereço do plugin.
- resultados/relatorio.md: consolidação editorial dos resultados e ajustes; não é apresentada como retorno original.
- scripts/analisar.py: código novo para reprodução, acrescentado nesta preparação.

## Cobertura do histórico

Não é uma exportação integral de todas as conversas anteriores. O enunciado original foi fornecido, mas as respostas completas da autora às quatro etapas e sua avaliação original não estão disponíveis neste registro. O prompt completo de criação e outras interações fora desta conversa não foram recuperados integralmente. Não foram inventados diálogos para preencher essas lacunas. Respostas repetidas de revisão foram consolidadas.

## Estrutura e publicação

A estrutura foi alinhada ao repositório analise-indicadores-okr de dthaissantos: README central com índice e pasta cases com documentação própria de cada case. Este projeto amplia os materiais para registrar dados, instruções, prompts, retornos e validação.
