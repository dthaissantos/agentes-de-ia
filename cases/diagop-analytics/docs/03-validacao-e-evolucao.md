## Critérios de aceitação do assistente

- Diferenciar o que os dados mostram de uma possível explicação.
- Informar quando uma regra não foi definida, antes do resultado afetado.
- Mostrar IDs ou filtros que permitam conferir os achados.
- Não confundir repetição com falha de comunicação.
- Não afirmar sobrecarga sem demanda, capacidade e fila.
- Não considerar dados fictícios como problemas reais.
- Manter validação humana e explicar sem exigir conhecimento prévio.

Esses critérios são uma revisão qualitativa do comportamento observado. Não foi realizado benchmark formal com múltiplas bases ou avaliação independente.
