# Dicionário provisório

Descrições baseadas nos nomes e valores do arquivo. As regras operacionais ainda precisam de validação.

| Campo | Descrição |
|---|---|
| id_atendimento | ID do registro de atendimento |
| canal | Canal registrado |
| motivo_contato | Motivo informado; contém categoria a validar |
| inicio_atendimento | Início registrado; fuso não declarado |
| fim_atendimento | Fim registrado; vazio para pendentes |
| sistemas_consultados | Lista de sistemas separada por ponto e vírgula |
| quantidade_sistemas | Quantidade informada, sujeita a conferência |
| tempo_consulta_min | Tempo numérico de consulta em minutos; definição a validar |
| departamento_acionado | Área acionada ou Nenhum |
| encaminhamento_em | Data/hora de encaminhamento |
| resposta_departamento_em | Data/hora de resposta da área |
| status | Concluído ou Pendente |
| complexidade | Classificação informada, sem regra documentada |
| id_cliente_pseudo | ID pseudonimizado de cliente |
| id_pedido | ID de pedido; um valor ausente |
| informacao_disponibilizada | Tipo de informação disponibilizada |
| tipo_contato | Classificação de contato inicial ou recontato |
| observacao_qualidade | Nota de qualidade; conferir com outros campos |
